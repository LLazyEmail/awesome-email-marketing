# +12% more subscribers (email-only form)

Opt-in forms often ask for name and email.

An A/B test reported that asking for **just an email** increased conversions by **12.44%** compared with asking for name and email.

Source: [Leadpages — how many fields on an opt-in form](https://www.leadpages.com/blog/ab-test-how-many-fields-opt-in-form/)
