# +181% better opt-in rate (Gmail targeting)

Periscopix used Gmail Ads targeting and reported a 181% boost in opt-in rate.

Case study: [World-first Gmail ads](http://www.periscopix.co.uk/clients/case-studies/world-first-gmail-ads)

A Gmail ad looks like a regular email in the inbox, so it reaches people who are already using email.

## How the original notes describe setup

1. When choosing how to target ads, use a different targeting method.
2. Choose **Placements**.
3. Search for Gmail.
4. Add `mail.google.com` from the list.
5. After confirming the campaign: Ads → + Ad → Ad gallery.
6. Choose Gmail Ads and fill in the fields.

The notes also say to format the ad for smaller screens and keep it fast to load, because most Gmail users open mail on mobile.

These UI steps are from older Google Ads / Gmail Ads docs and may have changed. Confirm against current Google Ads placement options before running a campaign.

Source: [Neil Patel — beginner's guide to Gmail ads](https://neilpatel.com/blog/the-beginners-guide-to-gmail-ads)
