# Public API

Machine-readable exports of the curated library. All endpoints are static JSON files published with the site.

Base URL:

```text
https://llazyemail.github.io/awesome-email-marketing/api/v1/
```

## Endpoints

| Endpoint | Description |
| --- | --- |
| [`catalog.json`](pathname:///api/v1/catalog.json) | Full tagged resource catalog |
| [`metrics.json`](pathname:///api/v1/metrics.json) | Counts by section and tag |
| [`glossary.json`](pathname:///api/v1/glossary.json) | Glossary terms and definitions |
| [`docs-pages.json`](pathname:///api/v1/docs-pages.json) | Auto-generated list of every docs markdown page |
| [`industry-leaders.json`](pathname:///api/v1/industry-leaders.json) | Articles scraped from every Industry Leaders source page |

## Catalog item shape

```json
{
  "id": "mailchimp",
  "name": "Mailchimp",
  "url": "https://mailchimp.com/",
  "description": "Free emailing software",
  "section": "tools",
  "sourcePage": "/docs/tools/best-tools",
  "tags": ["esp", "free", "newsletter"]
}
```

## Industry Leaders article shape

Regenerated from `website/docs/industry-leaders/**` by `npm run generate:industry-leaders` (and the **Update industry-leaders articles API** workflow on `main`).

```json
{
  "title": "Email marketing guide",
  "url": "https://mailchimp.com/resources/email-marketing-guide/",
  "heading": "Articles",
  "source": "mailchimp",
  "topic": "esp-blogs",
  "sourcePage": "/docs/industry-leaders/esp-blogs/mailchimp"
}
```

## Example

```bash
curl -s https://llazyemail.github.io/awesome-email-marketing/api/v1/catalog.json | jq '.items | length'

curl -s https://llazyemail.github.io/awesome-email-marketing/api/v1/industry-leaders.json | jq '.articleCount'
```

Filter client-side by tag, or use the interactive [Explore](/explore) page.

## LLM / agent exports

Built automatically with each site build (see issue [#223](https://github.com/LLazyEmail/awesome-email-marketing/issues/223)):

| Path | Description |
| --- | --- |
| [`/llms.txt`](pathname:///llms.txt) | [llmstxt.org](https://llmstxt.org/) index of documentation pages |
| [`/llms-full.txt`](pathname:///llms-full.txt) | Full docs corpus concatenated for LLM context |
| Doc `.md` URLs | Append `.md` to a docs URL (via markdown source plugin), or use per-page markdown files from the LLMs plugin |
| Copy page button | On docs pages — copy clean Markdown or open in ChatGPT / Claude / Gemini / Perplexity |
| [AgentReady MCP](https://www.agentready.it.com/api/mcp) | Docs are re-indexed after each production build for MCP clients |

## Regenerating locally

```bash
cd website
npm run generate:api
npm run generate:docs-index
npm run generate:industry-leaders
```

The catalog generator parses selected docs pages into `src/data/catalog.json` and `static/api/v1/*`.
The Industry Leaders generator writes `static/api/v1/industry-leaders.json`.
LLM files (`llms.txt`, `llms-full.txt`, per-page markdown) are produced during `npm run build`.
