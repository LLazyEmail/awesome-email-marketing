# Awesome Email Marketing website

This directory contains the [Docusaurus](https://docusaurus.io/) site for the Awesome Email Marketing list.

## Getting started

```bash
cd website
npm install
npm start
```

Open [http://localhost:3000/awesome-email-marketing/](http://localhost:3000/awesome-email-marketing/).

## Useful commands

- `npm start` — local development server
- `npm run build` — production build
- `npm run serve` — serve the production build locally
- `npm run deploy` — deploy to GitHub Pages

## Content

Documentation lives in `docs/`:

- `awesome-list.md` — main curated resource list
- `services.md` — services overview
- `opt-in-tactics.md` — opt-in conversion tactics
